## The title

> Chief Morale Officer for Abandoned Shopping Carts

49 characters. Somewhere out there, a person in a hi-vis vest is pep-talking
lonely shopping carts in a car park, telling them they are still wanted.

## How it works

`main.py` (Python 3, stdlib only, no network, deterministic) writes exactly
that one job title to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`
when set). It validates the title first — 1–60 characters, valid UTF-8,
single line, non-whitespace, no control characters — then verifies the file
by reading it back.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
